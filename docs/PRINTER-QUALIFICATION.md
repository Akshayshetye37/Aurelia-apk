# Printer physical qualification matrix

This matrix is evidence-based. A trusted LAN endpoint or an operator-confirmed generic test page does not establish compatibility for every model, firmware, media width, or ESC/POS dialect.

## Qualification gate

A row may move to QUALIFIED only after recording the exact manufacturer/model/firmware, transport, media width, printable dot width, DPI, charset, density, cutter behavior, and dated physical test evidence. The test must include invoice/receipt and kitchen-ticket output where applicable. A generic calibration confirmation is device-level trust evidence only; it is not a model-wide compatibility claim.

Unqualified models may be used only in explicitly supervised testing. Do not advertise universal 50–80 mm support or production eligibility from the presence of a LAN trust record.
