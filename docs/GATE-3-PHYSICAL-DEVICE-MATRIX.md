# Gate 3 physical-device qualification matrix

Copy and complete `docs/GATE-3-PHYSICAL-DEVICE-MATRIX.json` for the frozen candidate. Every case G3-01 through G3-10 must be `PASS`; record the exact candidate SHA and APK hash, device model/API (API 24+ for hardware-attested recovery), reviewer, timestamp and the commit that contains the signed matrix. The evidence validator requires the signoff commit to equal the control-branch commit running Gate 3.

The matrix is not qualification evidence until the real tests are performed. Do not record OTPs, raw phone numbers, credentials, device serials or secrets.
