# Aurelia release status

This file is a pointer, not a manually maintained gate ledger. The authoritative, per-run status report is generated by the `R1 governance CI` workflow from the exact commit's executed checks and published as the `r1-status-<commit-sha>` artifact named `STATUS.md`.

- [Open R1 governance workflow runs](https://github.com/Akshayshetye37/Aurelia-apk/actions/workflows/r1-governance.yml)
- [Open release-tag verification runs](https://github.com/Akshayshetye37/Aurelia-apk/actions/workflows/release-tag-guard.yml)

A packet is not complete unless every checkbox in [the Definition of Done](docs/DEFINITION_OF_DONE.md) is checked and evidence is linked. Repository-admin controls and human/device sign-offs remain blockers until independently evidenced.

**Release safety:** R1 is local-first. `uiCutover`, cloud sync, and live gateway payments must remain OFF. Production release remains unauthorized until Packet 11 is accepted.
